# 👜쿠팡 페이지 기능 테스트 실습

## 📌개요 
- 쿠팡 웹사이트의 주요 기능 테스트 
- *Selenium*과 *Pytest*를 활용하여 기능 자동화

---

### ✅테스트 항목
- 🔍**검색 기능**: 키워드 검색이 정상적으로 수행되는지 확인
- 🏷️**상품 상세 페이지 이동**: 검색 결과에서 상품을 클릭하면 올바른 페이지로 이동하는지 확인
- 🛒**장바구니 추가**: 상품이 장바구니에 정상적으로 추가되는지 확인
